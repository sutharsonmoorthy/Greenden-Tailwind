🌿 Greenden

Greenden is a simple and responsive plant website built using HTML and Tailwind CSS.
It is created to practice frontend design and responsive layouts.

📌 About the Project

This project helps in learning:
Tailwind CSS
Responsive web design
Mobile navigation without JavaScript
Clean UI design

🛠️ Technologies Used

HTML
Tailwind CSS

📱 Features

Responsive design
Mobile and desktop navbar
CSS-only hamburger menu
Simple and clean layout

🚀 How to Use

Download or clone the project
Open index.html in a browser
No setup required

🎯 Purpose

This project is made to:
Practice frontend skills
Learn Tailwind CSS

Build a basic website layout
